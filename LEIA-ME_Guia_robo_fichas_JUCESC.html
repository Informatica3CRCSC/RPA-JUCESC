Serviço RPA da JUCESC

Consulta CNPJs no site público da JUCESC com Playwright. O mesmo fluxo pode ser acionado localmente pelo CLI legado ou pela API FastAPI.

1. Executar como serviço HTTP

  1. Instale Python 3.10+ e execute instalar.bat para instalar FastAPI, Uvicorn, Playwright e Chromium.
  2. Execute iniciar_api.bat. A API escuta localmente em http://127.0.0.1:8000; a documentação interativa está em http://127.0.0.1:8000/docs.
  3. Envie CNPJs por JSON em POST /consultas ou arquivo .txt/.csv por POST /consultas/arquivo, incluindo CPF, nome e e-mail do solicitante. A requisição aguarda o lote terminar e responde com resultados e URLs dos arquivos.
  4. Baixe o CSV e os PDFs pelas URLs retornadas. Os arquivos ficam em outputs/<consulta_id>; proteja essa pasta e limpe-a conforme a política do servidor.
Segurança: esta versão não tem autenticação e deve ficar somente em rede privada/confiável; não exponha diretamente à Internet. Se clientes remotos precisarem acessar, configure a rede/firewall e use --host 0.0.0.0 conscientemente. O timeout HTTP deve comportar a duração do lote.

Exemplo de JSON para POST /consultas:

{"cnpjs":["12.345.678/0001-95"],"cpf_solicitante":"529.982.247-25","nome_solicitante":"Nome Sobrenome","email_solicitante":"nome@example.com"}

2. Executar pelo terminal (CLI legado)

O fluxo antigo continua disponível por rodar.bat. A API e o CLI usam o mesmo código de automação; o CLI lê cnpjs.txt e pode guardar o solicitante no perfil local.

3. Instalação pela primeira vez (uma vez por computador)

  1. Instale o Python. Entre em python.org → Downloads → baixe a versão para Windows e abra o instalador. Na primeira tela, marque "Add python.exe to PATH" e clique em Install Now. (Se o computador for do trabalho e pedir senha de administrador, peça à TI.)
  2. Copie a pasta do robô robo_fichas_jucesc para o seu computador (por exemplo, em Documentos). Se recebeu um .zip: botão direito → Extrair tudo.
  3. Dê dois cliques em instalar.bat. Ele instala o Playwright e um navegador de reserva. Espere aparecer "Instalação concluída". Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo (só para os arquivos da cópia oficial).
  4. Pronto. Não precisa repetir, a não ser que troque de computador.
Se aparecer "'python' não é reconhecido", o Python foi instalado sem marcar "Add python.exe to PATH". Desinstale, instale de novo marcando a opção e rode o instalar.bat outra vez.

4. Como usar o CLI legado

  1. Preencha o cnpjs.txt (na pasta do robô) com o Bloco de Notas: um CNPJ por linha, com ou sem pontuação, até 20. Salve.
  2. Dê dois cliques em rodar.bat. A janela preta mostra a impressão digital do robô, a lista de CNPJs lida e o resultado da validação. CNPJ com dígito errado é apontado antes de consultar.
  3. Na primeira vez, o robô pede os dados do solicitante exigidos pela JUCESC (os seus: CPF, nome completo e e-mail). O CPF não aparece enquanto você digita. Ele pergunta se pode guardar esses dados neste computador; responda S para não precisar digitar nas próximas vezes.
  4. Confira a lista e aperte ENTER. O robô consulta um CNPJ por vez, com pausa entre eles. Não precisa fazer nada.
  5. No fim, aperte ENTER para fechar a janela.

Trocar o solicitante (ex.: outra pessoa vai usar o computador): dois cliques em trocar_solicitante.bat; na próxima execução ele pede os dados de novo.

5. Onde ficam os resultados do CLI

  • Pasta fichas_jucesc_AAAA-MM-DD_HHMM, dentro da pasta do robô.
  • jucesc_<cnpj>.pdf: uma ficha por CNPJ.
  • resultados_jucesc.csv: abra primeiro (no Excel). Mostra o status (success/error), arquivo e erro de cada CNPJ. É gravado a cada CNPJ, então nada se perde se o robô parar no meio.
  • jucesc_<cnpj>_erro.png: print da tela quando algo falhou.

8. Impressão digital

A impressão digital publicada para a versão original v19 não corresponde mais ao código após a adaptação para API. Não use o hash antigo para validar esta versão. Publique um novo hash junto à cópia oficial quando ela for distribuída.

9. Compartilhar com colegas

A pasta do robô pode ser compartilhada, porque não contém dados pessoais (o cnpjs.txt vai vazio e os dados do solicitante ficam no computador de cada um). Siga o mesmo procedimento do robô do REGIN: autorização da chefia/TI, cópia oficial em pasta institucional só para leitura, cada colega instala no próprio computador, informa os próprios dados de solicitante e confere a impressão digital.

10. Manutenção

  • Ajustes de comportamento ficam no topo do arquivo: MAX_CNPJS_POR_EXECUCAO, SALVAR_PRINT_RESULTADO, MOSTRAR_NAVEGADOR. Não altere DOMINIO_PERMITIDO sem necessidade.
  • Se o site da JUCESC mudar, o ponto a ajustar é a lista de candidatos em _localizar_icone_ficha() e _voltar_para_busca().
  • Se quebrar depois de o Chrome atualizar: no Prompt da pasta, python -m pip install --upgrade playwright.
  • Toda alteração muda a impressão digital: publique a nova neste guia.
